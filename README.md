# 3 Stripes. 3 Steps.

Website: mostafa.page
Bewerbung: Duales Studium IT / Cyber Security 2027 bei adidas  

---

In meiner Selbstpräsentation habe ich erwähnt, dass dieses Projekt innovativ ist. Hier ist der Grund:

Recruiter brauchen Zeit für eine Entscheidung. Am Ende muss man immer überlegen: Wer behauptet nur etwas im Lebenslauf, und wer zieht es wirklich durch?

Hier muss man das nicht erraten. Ab dem Tag, an dem die Seite online ging, wird jede Minute Fokuszeit live gesammelt. Alles ab jetzt läuft direkt in die Datenbank und zwar streng gemessen über den Browser, nur bei echter Arbeit an CS50 und Mathe.

So sehen Recruiter und die IT-Fachabteilung genau: Was hat er versprochen? Stimmen die Zahlen? Reicht der Einsatz für das, was adidas erwartet?

Wie das Ganze technisch funktioniert, steht auf der Website im Bereich „The Backend“.

Danke fürs Reinschauen und hoffentlich hilft das bei der Entscheidung.
